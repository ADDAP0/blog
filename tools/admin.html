万一本地全没了（连代码都没了）

  1. 1. 装 Node.js 去 nodejs.org 下载 LTS 版，一路下一步即可
  2. 2. 把仓库拉回来 随便找个文件夹，打开终端跑这一行：
    git clone https://github.com/ADDAP0/blog.git
  3. 3. 打开写作后台 双击 tools\启动后台.vbs。桌面图标没了就跑一次 tools\安装快捷方式.ps1

文章、图片、音乐、站点代码、这个写作后台本身，全都在仓库里。 拉回来就是完整的一份，不用重新配任何东西。

想再多一份保险

  • GitHub 本身就是异地备份，而且带完整历史，删错了也能翻回来
  • 想更踏实的话，把项目文件夹复制一份到移动硬盘 —— 离线、不依赖网络
  • 或者在 GitHub 仓库页面点 Code → Download ZIP，存一份快照
